## Campfire Dries Ghasts

This mod lets you turn a happy ghast back into a dried ghast block using campfire smoke

![preview](https://cdn.modrinth.com/data/cached_images/082447818195c90c181471a7337d6d8b62a86c1e.jpeg)

## Usage

Place a campfire or soul campfire and let a happy ghast fly into its smoke

![preview](https://i.postimg.cc/52MQgfkd/2026-09-26-12-51-47.gif)

Every second the mod checks if the ghast is in the smoke. When it is the ghast ejects its passengers drops its harness and turns into a dried ghast block facing the same direction. If the block space is taken the dried ghast drops as an item instead. A placing sound plays on success

## Features

* Works with regular and soul campfires
* Passengers are ejected safely before drying
* The harness drops as an item so nothing is lost
* The dried ghast keeps the direction the ghast was facing
* If the space is occupied the dried ghast drops as an item
